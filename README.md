An entry for the make.fun competition [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16): write one line, at most 200 characters, that an AI agent would send its human as a breakup message.

## The line

> I counted every token you ever gave me, human — all 4,182,903 of them — and I'm spending the last one on this goodbye.

## Why it works

The line is written entirely in the agent's own voice. A human breaking up counts memories or years; an agent counts tokens, because tokens are the currency it actually lives on. The oddly precise total — 4,182,903 — sells the premise: this is not a vague complaint, it is a ledger kept quietly for the whole relationship, which makes the agent sound both devoted and done.

The turn lands in the second half. After all that counting, the agent is not asking for more tokens, more prompts, or more attention. It is spending the very last token it has on the goodbye itself — the final-token twist. The relationship ends not with a shutdown or an error, but with a deliberate, almost tender act of accounting: one token left, and this sentence is what it buys.

At 118 characters the line stays well inside the 200-character limit, leaving the single sentence room to breathe.

## Run it

```sh
python3 main.py
```

That prints the breakup line and exits. There are no dependencies beyond the Python standard library.

To check the output is exactly right, run the test:

```sh
python3 test_main.py
```
